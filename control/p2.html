Understanding Sensor Dynamics

The sensor is modeled as a first-order system:

τs × d(Sensor Report)/dt = True Output - Sensor Report

When τs is small, the sensor responds quickly. When τs is large, the sensor responds slowly and introduces additional delay into the feedback loop.

This delay can make the controller react to outdated measurements, potentially causing increased overshoot or oscillations.
